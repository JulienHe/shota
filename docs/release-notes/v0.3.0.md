Shota can now update itself.

## Auto-update

Shota checks for a new version when it starts, and from a new **Check for Updates…** item in the tray menu. When one is found it asks before doing anything, then downloads, installs and restarts.

The check at launch is deliberately silent: if there's no network, or GitHub is having a bad day, nothing interrupts you. The tray item is the opposite — it always answers, including "you're already up to date", because you asked it a question.

Updates are verified against a signing key built into the app, so an installer that wasn't produced by this project is rejected rather than run.

**This is the first version that can update itself.** Nothing earlier knows how to look, so this one still has to be installed by hand — every version after it won't.

## Also in this release

- The Windows installer carries Shota's own icon instead of the generic NSIS globe.
- The README now leads with a real screenshot of the editor, generated from the live UI rather than posed by hand.

## Known rough edge

The installer still isn't code-signed, so Windows SmartScreen will warn you on first run: **More info → Run anyway**. That's a certificate problem rather than a code one, and it's unrelated to the update signing above.
