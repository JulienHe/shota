New: get images into Shota, and out of it.

- **Edit any image, not just screenshots.** Drop an image on the editor, press `Ctrl+V` to open whatever is on your clipboard, or use **Open Image…** and **Open from Clipboard** in the tray menu. Right-click an image in Explorer and choose **Edit with Shota** (on Windows 11 it's under *Show more options*; turn it off in Settings > General).
- **Drag the result into another app.** Grab the handle at the bottom of the editor and drop the image into Slack, an email, a browser, or a folder.
- **Share.** The new Share button opens the Windows Share sheet.
- **Print Screen works again.** On some Windows 11 setups the system kept the key even with the Snipping Tool shortcut turned off, so Shota's default capture shortcut did nothing. It now takes the key itself.
- Starting Shota a second time hands over to the copy that's already running instead of fighting it for the shortcuts.

---

**Install:** get Shota from the [Microsoft Store](https://apps.microsoft.com/detail/9n4x6b0ctgp5), which keeps it up to date for you. You can also download `Shota_0.7.0_x64-setup.exe` below. Windows 10 or 11.

If you already have Shota 0.3.0 or newer from GitHub, it will offer you this update itself.
