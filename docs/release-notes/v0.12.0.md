A calmer editor: the same tools, fewer things competing for attention.

- **Toolbar in clusters.** Tools are grouped by what they do (select, draw, emphasise, picture), with a divider between groups. Rectangle, ellipse and line share one button that remembers the one you used last; the small arrow beside it lists the others. Every tool keeps its shortcut.
- **A quieter bottom bar.** Only what you use every time stays there: drag out, Copy and Save. Share, Pin on screen, export size and projects are one click away in the **...** menu, which shows the export size when it is not 100%.
- **Menus that stay on screen.** Menus opened from the right edge of a window now line up with their button instead of running off it.

---

**Install:** get Shota from the [Microsoft Store](https://apps.microsoft.com/detail/9n4x6b0ctgp5), which keeps it up to date for you. You can also download `Shota_0.12.0_x64-setup.exe` below. Windows 10 or 11.

If you already have Shota 0.3.0 or newer from GitHub, it will offer you this update itself.
