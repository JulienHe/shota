Shota now speaks 15 languages, and its shortcuts follow Windows conventions.

## Languages

English, French, German, Spanish, Italian, Portuguese (Brazil), Dutch, Polish, Turkish, Russian, Ukrainian, Japanese, Korean, and Simplified and Traditional Chinese. That covers the whole interface, including the tray menu and the update dialogs, not just the parts drawn in the window.

Shota follows your Windows language automatically and falls back to English if yours isn't on the list. You can also pick one yourself in **Settings… → Language**. Choosing "Match system" hands it back to Windows.

Regional variants are matched sensibly: `fr-CA` gets French, `zh-CN` gets Simplified Chinese, `zh-TW` and `zh-HK` get Traditional Chinese, and Portuguese from Portugal gets the Brazilian translation rather than English.

A note on quality: the translations were produced for this release and checked for terminology, not reviewed by native speakers of every language. If something reads awkwardly, especially a tool name, [open an issue](https://github.com/JulienHe/shota/issues) and it will be fixed. The strings live in `locales/` as plain JSON, so corrections are a small pull request.

## Shortcuts

The defaults were Ctrl+Shift+3 and Ctrl+Shift+4, carried over from macOS. Shota now uses the key Windows screenshot tools have always used:

| Action | New default |
|---|---|
| Capture an area or window | `Print Screen` |
| Capture the full screen | `Ctrl` + `Print Screen` |
| Open history | `Shift` + `Print Screen` |

If you've changed your shortcuts, or saved a capture with Shota before, your current capture shortcuts are kept. History moves to `Shift` + `Print Screen` for everyone.

Windows 11 gives Print Screen to the Snipping Tool by default, which silently swallows the key. When that's the case, Settings shows a notice with a button that hands the key to Shota. It changes one per-user Windows setting and needs no admin rights.

## Also

- The tray's "Keyboard Shortcuts…" entry is now **Settings…**, since it holds more than shortcuts.
