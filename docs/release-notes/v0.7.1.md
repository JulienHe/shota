Print Screen is reliable now.

- **Print Screen opens the capture on the first press.** On some Windows 11 setups it needed a second press: Windows sometimes delivers only half of a Print Screen press, and Shota only listened for the other half.
- **Focus goes back to the app you were in.** After Copy, Save, closing the editor or pressing `Esc` in the capture overlay, Shota used to leave the keyboard on an invisible window until you clicked something else, so the next Print Screen did nothing. It now hands focus back to the app you came from.

---

**Install:** get Shota from the [Microsoft Store](https://apps.microsoft.com/detail/9n4x6b0ctgp5), which keeps it up to date for you. You can also download `Shota_0.7.1_x64-setup.exe` below. Windows 10 or 11.

If you already have Shota 0.3.0 or newer from GitHub, it will offer you this update itself.
