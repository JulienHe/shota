One fix.

- **Print Screen opens the capture on the first press.** Some Windows 11 setups needed a second press: the capture overlay appeared without the keyboard, so `Esc` did nothing and the first press seemed to be lost. Shota now takes the keyboard properly when it opens the overlay.

---

**Install:** get Shota from the [Microsoft Store](https://apps.microsoft.com/detail/9n4x6b0ctgp5), which keeps it up to date for you. You can also download `Shota_0.7.1_x64-setup.exe` below. Windows 10 or 11.

If you already have Shota 0.3.0 or newer from GitHub, it will offer you this update itself.
