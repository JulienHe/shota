Shota now speaks seven languages.

## Languages

English, French, German, Spanish, Japanese, Korean and Simplified Chinese — the whole interface, including the tray menu and the update dialogs, not just the parts drawn in the window.

Shota follows your Windows language automatically. If that language isn't one of the seven, it falls back to English. You can also pick a language explicitly in **Keyboard Shortcuts… → Language**, which overrides the system setting; choosing "Match system" hands it back.

The matching is forgiving about regional variants: `fr-CA`, `fr-FR` and plain `fr` all land on French, and `zh-Hans-CN` finds Simplified Chinese.

A note on quality: the translations were produced as part of this release and reviewed for terminology, not by native speakers of every language. If something reads awkwardly — especially tool names — [open an issue](https://github.com/JulienHe/shota/issues) and it will be fixed. The strings live in `locales/` as plain JSON, so corrections are a small pull request.
