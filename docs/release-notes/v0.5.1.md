A maintenance release. Nothing changes in the app itself: same features, same behaviour as 0.5.0.

## Security

- **source-map-js updated to 1.2.2**, fixing a denial-of-service issue reported by Dependabot. It is only used while building Shota's interface and was never part of the installed app, so no installed copy was exposed.
- **glib advisory reviewed and dismissed.** glib only enters the build through Tauri's Linux support. Shota ships for Windows only, so it was never compiled into any release.

If you're on 0.5.0, you lose nothing by skipping this one, and gain nothing but a tidier version number by taking it.

---

**Install:** download `Shota_0.5.1_x64-setup.exe` below, or get it from the [Microsoft Store](https://apps.microsoft.com/detail/9n4x6b0ctgp5). Windows 10 or 11.

If you already have Shota 0.3.0 or newer from GitHub, it will offer you this update itself.
