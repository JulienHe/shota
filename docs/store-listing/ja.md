## Description

```
Shota は、Windows 向けの高速でネイティブなスクリーンショット＆注釈ツールです。

Print Screen キーで範囲をキャプチャしたりウィンドウにスナップしたり、Ctrl+Print Screen で画面全体をキャプチャしたりできます。キャプチャはすぐに軽快なエディターで開くので、さっと書き込んで作業に戻れます。

注釈
四角形、楕円、直線、矢印を描けます。システムにインストールされている任意のフォントでテキストを追加できます。フリーハンドで描くことも。自動で番号が振られるステップで、手順を順番に案内できます。本物のマーカーのように蛍光ペンで文字をなぞれます。一部をスポットライトで目立たせ、残りを暗くできます。見せたくない部分はぼかしやモザイクで隠せます。

すばやく仕上げる
ワンクリックでクリップボードにコピーまたは保存すると、エディターはすぐに閉じます。PNG、JPG、WebP で、好きなフォルダーに「Shota 2026-10-11 14-05-09」のような名前で保存できます。

自分好みに
キャプチャのキーからエディターの各ツールまで、どのショートカットも変更できます。ライト、ダーク、Windows に合わせる、から選べます。サインイン時に Shota を起動できます。15 か国語に対応しています。

データは PC の外に出ません
アカウントもサインインも、分析もテレメトリもありません。スクリーンショットはお使いの PC で処理され、ご自身のディスクに保存されます。どこにもアップロードされません。

すべてのキャプチャを保存
最近のキャプチャはローカルの履歴に残ります。注釈をそのままに開き直したり、もう一度コピーしたり、削除したりできます。何件、どのくらいの期間残すかは自分で決められます。

Shota は MIT ライセンスの無料オープンソースソフトウェアです。ソースコードは github.com/JulienHe/shota にあります。
```

## Short description

```
Windows 向けの高速でネイティブなスクリーンショット＆注釈ツール。画面全体、範囲、ウィンドウをキャプチャして、矢印、テキスト、蛍光ペン、番号付きステップ、スポットライト、ぼかしで書き込めます。アカウント不要、テレメトリなし、アップロードなし。
```

## What's new in this version

```
Shota が 15 か国語に対応しました：英語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語 (ブラジル)、オランダ語、ポーランド語、トルコ語、ロシア語、ウクライナ語、日本語、韓国語、中国語 (簡体字・繁体字)。

新しい設定ウィンドウ：
• エディターの各ツールを含め、どのショートカットも変更可能
• PNG、JPG、WebP で、好きなフォルダーに、自分で決めたファイル名で保存
• ライト、ダーク、Windows に合わせる
• スタートアップ時に起動
• 履歴の保存量を選択、履歴の消去

Windows の他のツールと同じく、Print Screen が既定のキャプチャキーになりました。Windows が Snipping Tool 用にこのキーを確保している場合は、設定から Shota に割り当てられます。
```
