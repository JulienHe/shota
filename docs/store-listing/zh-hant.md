# Store listing: Chinese (Traditional) (`zh-hant`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota 是一款快速的原生 Windows 擷取畫面與標註工具。

按 Print Screen 擷取區域或貼齊視窗，按 Ctrl+Print Screen 擷取整個螢幕。擷取的畫面會立刻在輕量的編輯器中開啟，標註完就能繼續工作。

標註
繪製矩形、橢圓、直線和箭頭。使用系統中已安裝的任何字型加入文字。自由手繪。加入自動編號的步驟，一步步引導他人。像真正的螢光筆一樣劃過文字。用聚光燈凸顯一個區域，其餘部分變暗。把不想分享的內容模糊或打上馬賽克。

快速完成
一鍵複製到剪貼簿或儲存，編輯器隨即讓路。以 PNG、JPG 或 WebP 格式，儲存到你選擇的資料夾，檔名如「Shota 2026-10-11 14-05-09」。

隨你所好
從擷取按鍵到編輯器裡的每個工具，任何快速鍵都能修改。可選淺色、深色或跟隨 Windows。登入時自動啟動 Shota。支援 15 種語言。

資料不離開你的電腦
不需帳號，不需登入，沒有數據分析，沒有遙測。擷取畫面在你的電腦上處理，並儲存在你自己的磁碟。不會上傳到任何地方。

每張擷取畫面都會保留
最近的擷取畫面保存在本機歷程記錄中。可以帶著原有標註重新開啟、再次複製或刪除。保留多少張、保留多久，由你決定。

Shota 以 MIT 授權免費開源。原始碼位於 github.com/JulienHe/shota。
```

## What's new in this version

```
Shota 現在支援 15 種語言：英文、法文、德文、西班牙文、義大利文、葡萄牙文（巴西）、荷蘭文、波蘭文、土耳其文、俄文、烏克蘭文、日文、韓文，以及簡體中文和繁體中文。

全新的設定視窗：
• 任何快速鍵都能修改，包括編輯器中的每個工具
• 以 PNG、JPG 或 WebP 格式，儲存到你選擇的資料夾，並使用自訂檔名
• 淺色、深色或跟隨 Windows
• 開機時啟動
• 選擇保留多少歷程記錄，並可清除

與 Windows 其他工具一樣，Print Screen 現在是預設擷取鍵。如果 Windows 將它留給了剪取工具，設定中可一鍵交給 Shota。
```
