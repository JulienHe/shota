## Description

```
Shota 是一款快速的原生 Windows 截图与标注工具。

按 Print Screen 截取区域或吸附到窗口，按 Ctrl+Print Screen 截取整个屏幕。截图会立刻在轻量的编辑器中打开，标注完就能继续做事。

标注
绘制矩形、椭圆、直线和箭头。使用系统中已安装的任意字体添加文字。自由手绘。添加自动编号的步骤，一步步引导他人。像真正的记号笔一样用荧光笔划过文字。用聚光灯突出一个区域，其余部分变暗。把不想分享的内容模糊或打上马赛克。

快速完成
一键复制到剪贴板或保存，编辑器随即让路。以 PNG、JPG 或 WebP 格式，保存到你选择的文件夹，文件名形如“Shota 2026-10-11 14-05-09”。

随你所需
从截图按键到编辑器里的每个工具，任何快捷键都能修改。可选浅色、深色或跟随 Windows。登录时自动启动 Shota。支持 15 种语言。

数据不离开你的电脑
无需账户，无需登录，没有数据分析，没有遥测。截图在你的电脑上处理，并保存到你自己的磁盘。不会上传到任何地方。

每张截图都会保留
最近的截图保存在本地历史记录中。可以带着原有标注重新打开、再次复制或删除。保留多少张、保留多久，由你决定。

Shota 基于 MIT 许可证免费开源。源代码位于 github.com/JulienHe/shota。
```

## Short description

```
快速的原生 Windows 截图与标注工具。截取屏幕、区域或窗口，再用箭头、文字、荧光笔、编号步骤、聚光灯和模糊进行标注。无需账户，没有遥测，不上传任何内容。
```

## What's new in this version

```
Shota 现已支持 15 种语言：英语、法语、德语、西班牙语、意大利语、葡萄牙语（巴西）、荷兰语、波兰语、土耳其语、俄语、乌克兰语、日语、韩语，以及简体中文和繁体中文。

全新的设置窗口：
• 任何快捷键都可修改，包括编辑器中的每个工具
• 以 PNG、JPG 或 WebP 格式，保存到你选择的文件夹，并使用自定义文件名
• 浅色、深色或跟随 Windows
• 开机时启动
• 选择保留多少历史记录，并可清除

与 Windows 其他工具一样，Print Screen 现在是默认截图键。如果 Windows 将它留给了截图工具，设置中可一键交给 Shota。
```
