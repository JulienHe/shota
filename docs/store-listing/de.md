# Store listing: German (`de`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota ist ein schnelles, natives Screenshot- und Anmerkungstool für Windows.

Drücke die Druck-Taste, um einen Bereich aufzunehmen oder an einem Fenster einzurasten, oder Strg+Druck für den ganzen Bildschirm. Jede Aufnahme öffnet sich sofort in einem schlanken Editor: kurz markieren, weitermachen.

ANMERKEN
Zeichne Rechtecke, Ellipsen, Linien und Pfeile. Füge Text in jeder auf deinem System installierten Schriftart hinzu. Zeichne freihand. Setze automatisch nummerierte Schritte, um jemanden durch einen Ablauf zu führen. Fahre mit dem Textmarker über Text wie mit einem echten Stift. Hebe einen Bereich hervor und dunkle den Rest ab. Zeichne weich oder verpixle alles, was du nicht teilen möchtest.

SCHNELL FERTIG
Mit einem Klick in die Zwischenablage kopieren oder speichern, und der Editor ist aus dem Weg. Speichere als PNG, JPG oder WebP, im Ordner deiner Wahl, mit Dateinamen wie „Shota 2026-10-11 14-05-09“.

GANZ NACH DEINEM GESCHMACK
Ändere jedes Tastenkürzel, von den Aufnahmetasten bis zu jedem Werkzeug im Editor. Wähle hell, dunkel oder wie Windows. Starte Shota bei der Anmeldung. Nutze es in 15 Sprachen.

NICHTS VERLÄSST DEINEN COMPUTER
Kein Konto, keine Anmeldung, keine Analysen, keine Telemetrie. Deine Screenshots werden auf deinem Computer verarbeitet und auf deiner eigenen Festplatte gespeichert. Nichts wird irgendwohin hochgeladen.

JEDE AUFNAHME BLEIBT ERHALTEN
Die letzten Aufnahmen bleiben in einem lokalen Verlauf. Öffne eine mit allen Anmerkungen wieder, kopiere sie erneut oder lösche sie. Du entscheidest, wie viele bleiben und wie lange.

Shota ist kostenlos und Open Source unter der MIT-Lizenz. Der Quellcode liegt auf github.com/JulienHe/shota.
```

## Short description

```
Ein schnelles, natives Screenshot- und Anmerkungstool für Windows. Nimm den Bildschirm, einen Bereich oder ein Fenster auf und markiere mit Pfeilen, Text, Textmarker, Schritten, Spotlight und Weichzeichner. Kein Konto, keine Telemetrie, kein Upload.
```

## What's new in this version

```
Shota spricht jetzt 15 Sprachen: Englisch, Französisch, Deutsch, Spanisch, Italienisch, Portugiesisch (Brasilien), Niederländisch, Polnisch, Türkisch, Russisch, Ukrainisch, Japanisch, Koreanisch sowie vereinfachtes und traditionelles Chinesisch.

Ein neues Einstellungsfenster:
• Jedes Tastenkürzel änderbar, auch jedes Werkzeug im Editor
• Speichern als PNG, JPG oder WebP, im Ordner deiner Wahl, mit eigenen Dateinamen
• Hell, dunkel oder wie Windows
• Beim Start ausführen
• Bestimme, wie viel Verlauf Shota behält, und lösche ihn

Die Druck-Taste ist jetzt die Standardtaste für Aufnahmen, wie im restlichen Windows. Hält Windows sie für das Snipping Tool fest, bieten die Einstellungen an, sie an Shota zu übergeben.
```
