Paste each block into the field of the same name in Partner Center.

## Description

```
Shota is a fast, native screenshot and annotation tool for Windows.

Press Print Screen to capture a region or snap to a window, or Ctrl+Print Screen for the whole screen. Whatever you capture opens immediately in a lightweight editor, so you can mark it up and get on with your day.

ANNOTATE
Draw rectangles, ellipses, lines and arrows. Add text in any font installed on your system. Sketch freehand. Drop auto-numbering step badges to walk someone through a sequence. Swipe a highlighter over text like a real marker. Spotlight one region and dim everything else. Blur or pixelate anything you'd rather not share.

FINISH QUICKLY
Copy to the clipboard or save in one click, and the editor gets out of your way. Save as PNG, JPG or WebP, to the folder you choose, with file names like "Shota 2026-10-11 14-05-09".

MAKE IT YOURS
Change any shortcut, from the capture keys to every tool in the editor. Pick light, dark, or match Windows. Launch Shota when you sign in. Use it in 15 languages.

NOTHING LEAVES YOUR MACHINE
No account, no sign-in, no analytics, no telemetry. Your screenshots are processed on your computer and written to your own disk. Nothing is uploaded anywhere.

EVERY CAPTURE IS KEPT
Recent captures stay in a local history. Reopen one with its annotations intact, copy it again, or delete it. You decide how many to keep, and for how long.

Shota is free and open source under the MIT licence. The source code is at github.com/JulienHe/shota.
```

## Short description

```
A fast, native screenshot and annotation tool for Windows. Capture your screen, a region or a window, then mark it up with arrows, text, highlighter, step badges, spotlight and blur. No account, no telemetry, nothing uploaded anywhere.
```

## What's new in this version

```
Shota now speaks 15 languages: English, French, German, Spanish, Italian, Portuguese (Brazil), Dutch, Polish, Turkish, Russian, Ukrainian, Japanese, Korean, and Simplified and Traditional Chinese.

A new Settings window:
• Change any shortcut, including every tool in the editor
• Save as PNG, JPG or WebP, to a folder you choose, with your own file names
• Light, dark, or match Windows
• Launch at startup
• Choose how much history Shota keeps, and clear it

Print Screen is now the default capture key, like the rest of Windows. If Windows is holding it for the Snipping Tool, Settings offers to hand it to Shota.
```
