# Store listing: Korean (`ko`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota는 Windows용 빠르고 네이티브한 스크린샷 및 주석 도구입니다.

Print Screen을 눌러 영역을 캡처하거나 창에 맞추고, Ctrl+Print Screen으로 전체 화면을 캡처하세요. 캡처한 화면은 바로 가벼운 편집기에서 열리니, 표시만 하고 하던 일로 돌아가면 됩니다.

주석 달기
사각형, 타원, 선, 화살표를 그리세요. 시스템에 설치된 모든 글꼴로 텍스트를 추가하세요. 자유롭게 그릴 수도 있습니다. 번호가 자동으로 매겨지는 단계로 순서를 차근차근 안내하세요. 진짜 마커처럼 형광펜으로 텍스트를 칠하세요. 한 영역을 스포트라이트로 강조하고 나머지는 어둡게 하세요. 공유하고 싶지 않은 부분은 흐리게 하거나 모자이크 처리하세요.

빠르게 마무리
클릭 한 번으로 클립보드에 복사하거나 저장하면 편집기가 바로 비켜 줍니다. PNG, JPG, WebP 형식으로, 원하는 폴더에 "Shota 2026-10-11 14-05-09" 같은 이름으로 저장하세요.

내 마음대로
캡처 키부터 편집기의 모든 도구까지 어떤 단축키든 바꿀 수 있습니다. 밝게, 어둡게, Windows 설정 따르기 중에서 고르세요. 로그인할 때 Shota를 시작하세요. 15개 언어로 사용할 수 있습니다.

아무것도 PC 밖으로 나가지 않습니다
계정도, 로그인도, 분석도, 원격 분석(텔레메트리)도 없습니다. 스크린샷은 내 PC에서 처리되고 내 디스크에 저장됩니다. 어디에도 업로드되지 않습니다.

모든 캡처를 보관
최근 캡처는 로컬 기록에 남습니다. 주석이 그대로인 상태로 다시 열거나, 다시 복사하거나, 삭제하세요. 몇 개를 얼마 동안 보관할지는 직접 정합니다.

Shota는 MIT 라이선스의 무료 오픈 소스입니다. 소스 코드는 github.com/JulienHe/shota에 있습니다.
```

## Short description

```
Windows용 빠르고 네이티브한 스크린샷 및 주석 도구. 화면, 영역, 창을 캡처하고 화살표, 텍스트, 형광펜, 번호 단계, 스포트라이트, 흐리게로 표시하세요. 계정 없음, 텔레메트리 없음, 업로드 없음.
```

## What's new in this version

```
이제 Shota가 15개 언어를 지원합니다: 영어, 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어(브라질), 네덜란드어, 폴란드어, 튀르키예어, 러시아어, 우크라이나어, 일본어, 한국어, 중국어(간체 및 번체).

새 설정 창:
• 편집기의 모든 도구를 포함해 어떤 단축키든 변경
• PNG, JPG, WebP 형식으로, 원하는 폴더에, 원하는 파일 이름으로 저장
• 밝게, 어둡게, Windows 설정 따르기
• 시작 시 실행
• 기록 보관량 선택 및 기록 지우기

이제 Windows의 다른 도구처럼 Print Screen이 기본 캡처 키입니다. Windows가 캡처 도구용으로 이 키를 잡고 있다면, 설정에서 Shota에 넘겨줄 수 있습니다.
```
