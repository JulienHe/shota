## Description

```
Shota ~ швидкий нативний інструмент для знімків екрана та позначок у Windows.

Натисніть Print Screen, щоб зняти область або прив'язатися до вікна, або Ctrl+Print Screen, щоб зняти весь екран. Кожен знімок одразу відкривається в легкому редакторі: позначили потрібне й повернулися до справ.

ПОЗНАЧКИ
Малюйте прямокутники, еліпси, лінії та стрілки. Додавайте текст будь-яким шрифтом, установленим у системі. Малюйте від руки. Розставляйте автоматично пронумеровані кроки, щоб провести людину інструкцією. Проведіть маркером по тексту, як справжнім фломастером. Виділіть область прожектором і затемніть решту. Розмийте або сховайте пікселями все, чим не хочете ділитися.

ШВИДКО ГОТОВО
Скопіюйте в буфер обміну або збережіть одним клацанням, і редактор зникне з дороги. Зберігайте в PNG, JPG або WebP, у вибрану папку, з іменами на кшталт «Shota 2026-10-11 14-05-09».

ПІД СЕБЕ
Змінюйте будь-яке сполучення клавіш, від клавіш знімка до кожного інструмента редактора. Виберіть світлу, темну тему або як у Windows. Запускайте Shota під час входу в систему. Користуйтеся 15 мовами.

НІЩО НЕ ЗАЛИШАЄ ВАШ КОМП'ЮТЕР
Без облікового запису, без входу, без аналітики, без телеметрії. Знімки обробляються на вашому комп'ютері й зберігаються на вашому диску. Нічого нікуди не завантажується.

КОЖЕН ЗНІМОК ЗБЕРІГАЄТЬСЯ
Нещодавні знімки зберігаються в локальній історії. Відкрийте будь-який знову разом із позначками, скопіюйте ще раз або видаліть. Скільки зберігати й як довго, вирішуєте ви.

Shota безкоштовна й з відкритим кодом за ліцензією MIT. Вихідний код ~ на github.com/JulienHe/shota.
```

## Short description

```
Швидкий нативний інструмент для знімків екрана та позначок у Windows. Знімайте екран, область або вікно й позначайте стрілками, текстом, маркером, нумерованими кроками, прожектором і розмиттям. Без облікового запису, без телеметрії, без завантажень.
```

## What's new in this version

```
Shota тепер розмовляє 15 мовами: англійською, французькою, німецькою, іспанською, італійською, португальською (Бразилія), нідерландською, польською, турецькою, російською, українською, японською, корейською, а також спрощеною та традиційною китайською.

Нове вікно налаштувань:
• Будь-яке сполучення клавіш можна змінити, зокрема кожен інструмент редактора
• Збереження в PNG, JPG або WebP, у вибрану папку, з вашими іменами файлів
• Світла, темна тема або як у Windows
• Запуск під час входу в систему
• Вибір обсягу історії та її очищення

Print Screen тепер клавіша знімка за замовчуванням, як у всій Windows. Якщо Windows закріпила її за «Ножицями», налаштування запропонують віддати її Shota.
```
