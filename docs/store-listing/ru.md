# Store listing: Russian (`ru`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota ~ быстрый нативный инструмент для снимков экрана и пометок в Windows.

Нажмите Print Screen, чтобы снять область или привязаться к окну, или Ctrl+Print Screen, чтобы снять весь экран. Каждый снимок сразу открывается в лёгком редакторе: отметили нужное и вернулись к делам.

ПОМЕТКИ
Рисуйте прямоугольники, эллипсы, линии и стрелки. Добавляйте текст любым шрифтом, установленным в системе. Рисуйте от руки. Расставляйте автоматически пронумерованные шаги, чтобы провести человека по инструкции. Проведите маркером по тексту, как настоящим фломастером. Выделите область прожектором и затемните остальное. Размойте или скройте пикселями всё, чем не хотите делиться.

БЫСТРО ГОТОВО
Скопируйте в буфер обмена или сохраните одним щелчком, и редактор уйдёт с дороги. Сохраняйте в PNG, JPG или WebP, в выбранную папку, с именами вроде «Shota 2026-10-11 14-05-09».

ПОД СЕБЯ
Меняйте любое сочетание клавиш, от клавиш снимка до каждого инструмента редактора. Выберите светлую, тёмную тему или как в Windows. Запускайте Shota при входе в систему. Пользуйтесь на 15 языках.

НИЧЕГО НЕ ПОКИДАЕТ ВАШ КОМПЬЮТЕР
Без учётной записи, без входа, без аналитики, без телеметрии. Снимки обрабатываются на вашем компьютере и сохраняются на вашем диске. Ничего никуда не загружается.

КАЖДЫЙ СНИМОК СОХРАНЯЕТСЯ
Недавние снимки хранятся в локальной истории. Откройте любой из них снова вместе с пометками, скопируйте ещё раз или удалите. Сколько хранить и как долго, решаете вы.

Shota бесплатна и с открытым исходным кодом по лицензии MIT. Исходный код ~ на github.com/JulienHe/shota.
```

## Short description

```
Быстрый нативный инструмент для снимков экрана и пометок в Windows. Снимайте экран, область или окно и отмечайте стрелками, текстом, маркером, нумерованными шагами, прожектором и размытием. Без учётной записи, без телеметрии, без загрузок.
```

## What's new in this version

```
Shota теперь говорит на 15 языках: английском, французском, немецком, испанском, итальянском, португальском (Бразилия), нидерландском, польском, турецком, русском, украинском, японском, корейском, а также упрощённом и традиционном китайском.

Новое окно настроек:
• Любое сочетание клавиш можно изменить, включая каждый инструмент редактора
• Сохранение в PNG, JPG или WebP, в выбранную папку, с вашими именами файлов
• Светлая, тёмная тема или как в Windows
• Запуск при входе в систему
• Выбор объёма истории и её очистка

Print Screen теперь клавиша снимка по умолчанию, как во всей Windows. Если Windows закрепила её за «Ножницами», настройки предложат отдать её Shota.
```
