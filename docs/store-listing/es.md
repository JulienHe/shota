# Store listing: Spanish (`es`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota es una herramienta de capturas de pantalla y anotaciones rápida y nativa para Windows.

Pulsa Impr Pant para capturar una zona o ajustarte a una ventana, o Ctrl+Impr Pant para toda la pantalla. Cada captura se abre al instante en un editor ligero: la anotas y sigues con lo tuyo.

ANOTA
Dibuja rectángulos, elipses, líneas y flechas. Añade texto con cualquier fuente instalada en tu sistema. Dibuja a mano alzada. Coloca pasos numerados automáticamente para guiar a alguien paso a paso. Pasa un resaltador sobre el texto como un rotulador de verdad. Destaca una zona y oscurece el resto. Desenfoca o pixela lo que prefieras no compartir.

TERMINA RÁPIDO
Copia al portapapeles o guarda con un clic, y el editor se aparta. Guarda en PNG, JPG o WebP, en la carpeta que elijas, con nombres como «Shota 2026-10-11 14-05-09».

A TU MANERA
Cambia cualquier atajo, desde las teclas de captura hasta cada herramienta del editor. Elige tema claro, oscuro o el de Windows. Inicia Shota al iniciar sesión. Úsalo en 15 idiomas.

NADA SALE DE TU EQUIPO
Sin cuenta, sin inicio de sesión, sin analíticas, sin telemetría. Tus capturas se procesan en tu equipo y se guardan en tu propio disco. No se sube nada a ninguna parte.

CADA CAPTURA SE CONSERVA
Las capturas recientes quedan en un historial local. Vuelve a abrir una con sus anotaciones intactas, cópiala otra vez o elimínala. Tú decides cuántas conservar y durante cuánto tiempo.

Shota es gratuito y de código abierto con licencia MIT. El código fuente está en github.com/JulienHe/shota.
```

## Short description

```
Una herramienta de capturas y anotaciones rápida y nativa para Windows. Captura la pantalla, una zona o una ventana y anótala con flechas, texto, resaltador, pasos numerados, foco y desenfoque. Sin cuenta, sin telemetría, sin subir nada.
```

## What's new in this version

```
Shota ya habla 15 idiomas: inglés, francés, alemán, español, italiano, portugués (Brasil), neerlandés, polaco, turco, ruso, ucraniano, japonés, coreano, y chino simplificado y tradicional.

Una nueva ventana de Ajustes:
• Cambia cualquier atajo, incluidas todas las herramientas del editor
• Guarda en PNG, JPG o WebP, en la carpeta que elijas, con tus propios nombres de archivo
• Tema claro, oscuro o como Windows
• Iniciar con Windows
• Decide cuánto historial guarda Shota y bórralo

Impr Pant es ahora la tecla de captura predeterminada, como en el resto de Windows. Si Windows la reserva para la Herramienta Recortes, Ajustes ofrece cedérsela a Shota.
```
