# Store listing: Portuguese (Brazil) (`pt-br`)

Paste each block into the field of the same name in Partner Center.

## Description

```
O Shota é uma ferramenta de capturas de tela e anotações rápida e nativa para Windows.

Pressione Print Screen para capturar uma área ou encaixar em uma janela, ou Ctrl+Print Screen para a tela inteira. Cada captura abre na hora em um editor leve: você anota e segue com o seu dia.

ANOTE
Desenhe retângulos, elipses, linhas e setas. Adicione texto com qualquer fonte instalada no sistema. Desenhe à mão livre. Coloque etapas numeradas automaticamente para guiar alguém passo a passo. Passe o marca-texto sobre o texto como uma caneta de verdade. Destaque uma área e escureça o resto. Desfoque ou pixelize o que você prefere não compartilhar.

TERMINE RÁPIDO
Copie para a área de transferência ou salve com um clique, e o editor sai do caminho. Salve em PNG, JPG ou WebP, na pasta que você escolher, com nomes como "Shota 2026-10-11 14-05-09".

DO SEU JEITO
Altere qualquer atalho, das teclas de captura a cada ferramenta do editor. Escolha tema claro, escuro ou o do Windows. Inicie o Shota ao entrar no Windows. Use em 15 idiomas.

NADA SAI DO SEU COMPUTADOR
Sem conta, sem login, sem análises, sem telemetria. Suas capturas são processadas no seu computador e salvas no seu próprio disco. Nada é enviado para lugar nenhum.

TODA CAPTURA FICA GUARDADA
As capturas recentes ficam em um histórico local. Reabra uma com as anotações intactas, copie de novo ou exclua. Você decide quantas manter e por quanto tempo.

O Shota é gratuito e de código aberto, sob a licença MIT. O código-fonte está em github.com/JulienHe/shota.
```

## Short description

```
Uma ferramenta de capturas de tela e anotações rápida e nativa para Windows. Capture a tela, uma área ou uma janela e anote com setas, texto, marca-texto, etapas numeradas, destaque e desfoque. Sem conta, sem telemetria, nada enviado.
```

## What's new in this version

```
O Shota agora fala 15 idiomas: inglês, francês, alemão, espanhol, italiano, português (Brasil), holandês, polonês, turco, russo, ucraniano, japonês, coreano e chinês simplificado e tradicional.

Uma nova janela de Configurações:
• Altere qualquer atalho, incluindo cada ferramenta do editor
• Salve em PNG, JPG ou WebP, na pasta que você escolher, com seus próprios nomes de arquivo
• Tema claro, escuro ou igual ao Windows
• Iniciar com o Windows
• Escolha quanto histórico o Shota guarda e limpe-o

Print Screen agora é a tecla de captura padrão, como no resto do Windows. Se o Windows a reservar para a Ferramenta de Captura, as Configurações oferecem passá-la ao Shota.
```
