# Store listing: Polish (`pl`)

Paste each block into the field of the same name in Partner Center.

## Description

```
Shota to szybkie, natywne narzędzie do zrzutów ekranu i adnotacji dla Windows.

Naciśnij Print Screen, aby przechwycić obszar lub przyciągnąć do okna, albo Ctrl+Print Screen, aby zrobić zrzut całego ekranu. Każdy zrzut od razu otwiera się w lekkim edytorze: oznaczasz, co trzeba, i wracasz do pracy.

ADNOTACJE
Rysuj prostokąty, elipsy, linie i strzałki. Dodawaj tekst dowolną czcionką zainstalowaną w systemie. Rysuj odręcznie. Wstawiaj automatycznie numerowane kroki, by poprowadzić kogoś przez proces. Przeciągnij zakreślacz po tekście jak prawdziwym flamastrem. Wyróżnij jeden obszar i przyciemnij resztę. Rozmyj lub zpikselizuj wszystko, czego nie chcesz pokazywać.

SZYBKO GOTOWE
Skopiuj do schowka lub zapisz jednym kliknięciem, a edytor znika z drogi. Zapisuj jako PNG, JPG lub WebP, w wybranym folderze, z nazwami takimi jak „Shota 2026-10-11 14-05-09”.

PO TWOJEMU
Zmień dowolny skrót, od klawiszy przechwytywania po każde narzędzie edytora. Wybierz motyw jasny, ciemny lub zgodny z Windows. Uruchamiaj Shota po zalogowaniu. Korzystaj w 15 językach.

NIC NIE OPUSZCZA TWOJEGO KOMPUTERA
Bez konta, bez logowania, bez statystyk, bez telemetrii. Zrzuty są przetwarzane na Twoim komputerze i zapisywane na Twoim dysku. Nic nie jest nigdzie wysyłane.

KAŻDY ZRZUT ZOSTAJE ZACHOWANY
Ostatnie zrzuty zostają w lokalnej historii. Otwórz ponownie dowolny z nienaruszonymi adnotacjami, skopiuj go jeszcze raz lub usuń. Ty decydujesz, ile ich przechowywać i jak długo.

Shota jest darmowa i otwartoźródłowa, na licencji MIT. Kod źródłowy znajdziesz na github.com/JulienHe/shota.
```

## Short description

```
Szybkie, natywne narzędzie do zrzutów ekranu i adnotacji dla Windows. Przechwyć ekran, obszar lub okno i oznacz strzałkami, tekstem, zakreślaczem, numerowanymi krokami, reflektorem i rozmyciem. Bez konta, bez telemetrii, nic nie jest wysyłane.
```

## What's new in this version

```
Shota mówi teraz w 15 językach: angielskim, francuskim, niemieckim, hiszpańskim, włoskim, portugalskim (Brazylia), niderlandzkim, polskim, tureckim, rosyjskim, ukraińskim, japońskim, koreańskim oraz chińskim uproszczonym i tradycyjnym.

Nowe okno ustawień:
• Zmień dowolny skrót, w tym każde narzędzie edytora
• Zapisuj jako PNG, JPG lub WebP, w wybranym folderze, z własnymi nazwami plików
• Motyw jasny, ciemny lub jak w Windows
• Uruchamianie przy starcie
• Zdecyduj, ile historii przechowuje Shota, i wyczyść ją

Print Screen jest teraz domyślnym klawiszem przechwytywania, jak w całym Windows. Jeśli Windows rezerwuje go dla Narzędzia Wycinanie, ustawienia proponują przekazać go Shota.
```
